CurrencyPop

A menu bar popover that converts an amount — or a bit of arithmetic — between two currencies. No window, no Dock icon, no sign-in. Click the icon, type 1250+300*2, read the number, click away.

What it looks like

Design rules for the panel

Size

318 × 286 pt, fixed. Big enough for two full currency names, small enough to feel like a menu rather than a window.

Type

System font throughout. Amount and result in .monospacedDigit so the number stops jittering while you type.

Color

Only the result and the swap button carry the accent. Everything else is system label and secondary label, so it tracks macOS light/dark for free.

Motion

None, except the swap button's 180° rotation. A popover that animates its contents feels slow at this size.

Math in the field

+ − * / with real precedence, so 1250+300*2 is 1,850. The field never rewrites what you typed; it answers beside the label instead.

Half-typed input

1250+ is not an error. The result holds its last good value and the total beside the label dims until the expression parses again.

Empty state

Opens showing the last amount and pair, already converted. Never a blank field.

Offline

Stale rates still convert; the footer line turns to "ECB rate 26 Oct · offline" instead of hiding the result.

Build order

  1. New Xcode project5 min

    macOS App, SwiftUI lifecycle, name CurrencyPop. In Info.plist set LSUIElement to YES — no Dock icon, no app switcher entry.

  2. Turn the window into a menu bar item5 min

    Replace WindowGroup in the App struct. .menuBarExtraStyle(.window) is what gives a real panel instead of a dropdown menu.

    @main
struct CurrencyPopApp: App {
    var body: some Scene {
        MenuBarExtra("CurrencyPop", systemImage: "arrow.left.arrow.right") {
            ConverterView()
        }
        .menuBarExtraStyle(.window)
    }
}

  3. Lay out the panel15 min

    A VStack: amount TextField, from-picker, swap button, to-picker, Divider, result, footer. State in @AppStorage (amount, from, to) so it reopens exactly as you left it. .frame(width: 318) on the root view.

  4. Make the field do arithmetic10 min

    Foundation already evaluates expressions — NSExpression — so there is no parser to write and precedence comes for free. One catch worth knowing before you type it: on malformed input it raises an Objective-C exception that Swift cannot catch, and a field someone types into is malformed on almost every keystroke (1250+). The regex below is the whole safety story: nothing but a complete flat expression ever reaches it, and nil simply means "keep showing the last good result".

    /// "1250+300*2" -> 1850. nil while the expression is incomplete.
func evaluate(_ raw: String) -> Double? {
    let s = raw.filter { !$0.isWhitespace }
    // A number, then any run of (operator, number). Nothing else gets through —
    // NSExpression raises an uncatchable exception on bad syntax.
    guard s.range(of: #"^\d+(\.\d+)?([-+*/]\d+(\.\d+)?)*$"#,
                  options: .regularExpression) != nil else { return nil }
    return (NSExpression(format: s)
        .expressionValue(with: nil, context: nil) as? NSNumber)?.doubleValue
}

  5. Fetch and cache rates15 min

    One async call per base currency, triggered by .task on appear. Store the decoded dictionary plus its date in @AppStorage as JSON; skip the call if it is under an hour old.

    // https://api.frankfurter.dev/v1/latest?base=DKK
struct Rates: Codable {
    let base: String
    let date: String                 // "2026-10-28"
    let rates: [String: Double]      // ["VND": 3825.0, ...]
}

  6. Run it, then polish5 min

    Check four things by hand: 1250+300*2 converts 1,850 and not 3,100, a half-typed 1250+ leaves the last result standing instead of flashing zero, the swap button keeps the amount rather than the result, and quitting and relaunching restores the pair. Those four cover every bug this app can have.

The rate source

QuestionAnswer
Whofrankfurter.dev — open source, serves European Central Bank reference rates
KeyNone. No account, no header, no rate limit to speak of
Coverage~30 currencies: EUR, USD, GBP, DKK, SEK, NOK, JPY, VND and the rest of the ECB list. No crypto
FreshnessUpdated once per working day, around 16:00 CET. Weekend rates are Friday's
Good forTravel math, invoices, "is this expensive"
Not forTrading, or anything where the second decimal is money

If a currency outside the ECB list matters later, swapping in a keyed API is a change to one function.

One decision to make first

Menu bar icon (planned above) — always one click away, ~80 lines, nothing to configure.

Global hotkey panel — appears under the cursor on ⌥C, feels faster once it is muscle memory, but needs an NSPanel, a global event monitor and an Accessibility permission prompt. Roughly double the code and the only part that can break on a macOS update.

Starting with the menu bar does not block the hotkey: the panel view is the same either way.

Deliberately left out

  • —
    Rate history chartAdd when you catch yourself wondering whether now is a good time to transfer.
  • —
    Parentheses and percent in the fieldBoth widen the regex and reopen the crash NSExpression can throw; +10% also means modulo to it, not a tip. Add when flat + − * / genuinely runs out.
  • —
    CryptoDifferent API, different update cadence, different rounding. A second app, not a second picker.
  • —
    Favourites or multi-currency outputAdd when two pairs is not enough; the swap button covers most of it.
  • —
    Preferences windowThere is nothing to configure. If settings appear, that is the signal the app grew too far.
  • —
    Launch at login, auto-update, notarizationAdd on the day you want someone else to install it.
